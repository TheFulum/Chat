# Chat

Веб-чат на чистом PHP без фреймворков: регистрация, сообщения с вложениями, форматирование текста и фильтрация ленты.

## О проекте

Проект выполнен как практическое задание во время стажировки в компании Sotbit. Задача — реализовать чат с нуля, без фреймворков, с собственной простой архитектурой: отдельные слои для подключения к базе, моделей, логики обработки запросов и представлений. После сдачи чат был доработан и оптимизирован.

## Возможности

- **Регистрация и вход**: пароли хранятся в виде хеша (`password_hash`), при регистрации сохраняются IP-адрес и браузер пользователя.
- **Сообщения** с именем, email и текстом, отправка гостем или авторизованным пользователем.
- **Вложения**: изображения JPG, PNG и GIF с ограничением размеров (до 320×240 пикселей) и текстовые файлы до 100 КБ.
- **Форматирование текста** BB-кодами с кнопками на панели.
- **Лента сообщений** с постраничным выводом, фильтрацией по имени, email и дате и сортировкой по времени.
- Проверка форм на стороне клиента.

## Технологии

- PHP, MySQL (PDO, подготовленные запросы)
- JavaScript, Bootstrap 5
- Собственная структура в стиле MVC без фреймворков

## Структура

```
core/       подключение к базе, базовая модель, автозагрузка классов, сессии
models/     пользователи, сообщения, файлы
logical/    обработка форм чата и авторизации
views/      шаблоны страниц
wwwroot/    стили, скрипты, загруженные файлы
config.php  настройки базы и ограничений для файлов
```

## Запуск

Нужны PHP и MySQL (например, OpenServer или XAMPP). Укажите параметры базы в `config.php` вместо `YOUR_DB_PASSWORD` и откройте проект через локальный веб-сервер.
